# 💻 Virtualisation Basics (TryHackMe)

## 📚 Словарь / Основные понятия

* **Виртуализация (Virtualisation)** — технология, позволяющая одному физическому ПК (хосту) действовать как несколько раздельных виртуальных машин.
* **Гипервизор (Hypervisor)** — менеджер виртуальных машин, который распределяет ресурсы железа, создает и запускает ВМ (например, VirtualBox, VMware).
* **Лабораторная машина (Lab Machine / VM)** — виртуальный компьютер, функционирующий как отдельный физический ПК со своей собственной операционной системой.
* **Контейнер (Container)** — изолированная среда для запуска одного приложения и всех его зависимостей (делит ядро хостовой ОС, легкий и быстрый).
