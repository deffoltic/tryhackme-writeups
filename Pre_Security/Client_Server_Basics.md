# 🌐 Client-Server Basics (TryHackMe)

## 📡 Модель Клиент-Сервер (Client-Server Architecture)
* **Клиент (Client):** Устройство или приложение (например, браузер, `curl`), которое отправляет **запрос (Request)** к серверу.
* **Сервер (Server):** Удаленный компьютер, который обрабатывает запрос, ищет или генерирует данные и возвращает **ответ (Response)**.

---

## 🔹 IP-адреса и DNS
* **IP-адрес:** Уникальный числовой идентификатор устройства в сети (как адрес дома или номер телефона).
* **DNS (Domain Name System):** «Телефонная книга» интернета, которая связывает понятные человеку доменные имена (`google.com`) с их реальными IP-адресами (`142.250.180.14`).

---

## 📬 HTTP GET Method
* **GET** — метод HTTP-запроса, используемый для **получения** информации с сервера.
* **Передача данных:** Все параметры отправляются прямо в URL-строке после знака `?` (например, `site.com/search?q=test`).
* **Точка зрения ИБ (Security note):** 
  * Параметры в URL видна в истории браузера и логах сервера.
  * Значения параметров в GET-запросах — это первая точка для проверки на уязвимости (SQL-инъекции, IDOR и др.).
