# Linux Fundamentals — Part 1 (TryHackMe)

## 📁 Работа с файлами и директориями
* `ls` — показывает все объекты в текущей директории.
* `cd <folder>` — переход в указанную директорию.
* `pwd` — выводит полный путь текущей рабочей директории.
* `cat <file>` — выводит содержимое файла в терминал.
* `find` — поиск файлов по имени в файловой системе.
* `grep` — поиск заданного текста/шаблона внутри файла.

## ⚡️ Операторы командной строки (Shell Operators)
* `&` — фоновый режим (выполняет команду в фоне).
* `&&` — последовательное выполнение (вторая команда ждёт завершения первой).
* `>` — перенаправление вывода (полностью перезаписывает файл).
* `>>` — перенаправление вывода (добавляет данные в конец файла).
